HWiNFO logging: how to record sensors to a CSV file

HWiNFO logging writes sensor values to a CSV file while you play or run a workload. The steps below follow the answers the program's author gives in the vendor forum.

HWiNFO logging is started with the button at the bottom of the sensors window, which writes sensor values to a CSV file until you stop it. The Logged checkbox in the sensor settings decides which values go into the file. Manual logging works in the free edition; starting a log automatically from the command line is a Pro feature.

What the sensor log is

HWiNFO logging records every polled value of the sensors you select, one row per polling cycle, in a CSV file that spreadsheet programs open directly. It is the tool for questions a live view cannot answer: how hot the processor got during a two hour session, or whether a voltage dipped before a crash.

The sensor log is separate from the report file. A report is a snapshot of the hardware inventory in XML, CSV or HTML. The author notes that the report option to log all sensors affects only the report, not the sensor log.

Steps

  1. Open the sensors windowStart HWiNFO and tick Sensors-only on the welcome screen, or open the sensors from the full program. If you have not installed it yet, see the download page.
  2. Choose what to logOpen the sensor settings and go to the tab for customising values. Make sure Logged is enabled for each value you want in the file and that monitoring of that sensor is enabled.
  3. Start loggingUse the button at the bottom of the sensors window that starts and stops logging, and choose where to save the file.
  4. Run your workloadLeave HWiNFO running while you play or test. A new row is written on each polling cycle.
  5. Stop loggingPress the same button again. The file is complete once logging stops.
  6. Open the CSVImport the file into a spreadsheet, or load it in the Generic Log Viewer listed on the vendor's add ons page to plot and compare logs.

New to the sensors window? The guide to checking temperatures with HWiNFO covers Sensors-only mode, and the download page covers installation.

Keeping the file small

By default a log can contain hundreds of columns. The Logged checkbox is the filter: untick it for values you do not need and they stay out of the CSV. Disabling monitoring for whole sensors you never read also reduces the work done on every cycle.

Sensors that appear only after logging has started cannot be placed in the header at the top. HWiNFO adds a second header at the bottom of the file that lists those late sensors as well, so check the end of the file if a column seems to have no title.

Polling period and timing

The global polling period is 2000 ms by default and sets how often a row is written. It applies to all sensors; separate periods exist only for S.M.A.R.T. and embedded controller sensors, which are derived from the global value. Version 8.54 lowered the minimum period to 20 ms.

Do not expect exact spacing between rows. The author says millisecond precision is not achievable, and slow sensors stretch the interval. The Profiling Time column shows which sensors take longest to read, so you can disable them.

What Pro adds to logging

In the free edition a person has to press the button. Pro adds command line switches that start the sensors with logging automatically, set the polling rate, choose the log format and limit the run time. Version 8.54 also allows notes to be inserted into the JSON sensor log.

That matters for unattended test benches and scheduled jobs. The other differences are on the free vs Pro page, and licence costs are on the price page.

Frequently asked questions

How do I start logging in HWiNFO?

Open the sensors window and use the button at the bottom that starts and stops logging. Choose a file location, run your workload and press the button again to finish.

Where does HWiNFO save the log file?

In the location you choose when you start logging. The output is a CSV file that can be imported into Excel or another spreadsheet.

Why are some sensors missing from my log?

Check that Logged is enabled for those values in the sensor settings and that monitoring of the sensor is enabled. The report option to log all sensors does not affect the sensor log.

Can HWiNFO start logging automatically?

Only in Pro, which supports command line switches that start the sensors with logging. In the free edition logging is started by hand.

How do I view a HWiNFO log as a graph?

Open the CSV in a spreadsheet and chart the columns, or use the Generic Log Viewer from the vendor's add ons page, which is made for analysing and comparing HWiNFO logs.

Why is a header row at the bottom of my CSV?

Sensors that appeared after logging began could not be included in the first header. HWiNFO writes a second header at the end of the file that lists them too.
