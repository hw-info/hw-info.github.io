Cannot start MSI App Player: the virtualization conflict and how to fix it

If you see Cannot start MSI App Player, the cause MSI documents is a clash with other virtualization users on Windows: Hyper-V, VirtualBox, VMware or Memory integrity. Here are MSI's fixes in order, least invasive first.

The Cannot start MSI App Player message appears when another program or Windows feature is already using hardware virtualization. MSI's fix is to close VirtualBox or VMware, adjust Hyper-V, and if needed turn off Memory integrity under Core isolation in Windows Security, then restart. Also confirm that virtualization is enabled in the BIOS.

Why MSI App Player cannot start

MSI's knowledge base article No. 03632 explains the Cannot start MSI App Player warning. The emulator uses hardware assisted virtualization to run Android. If Hyper-V, VirtualBox, VMware or a similar tool already holds that feature, the emulator cannot take it and refuses to launch. Windows' Memory integrity setting, part of Core isolation, runs on the same hypervisor and can block it too.

The article dates from 2020. BlueStacks says its version 5.20 and later can run with Hyper-V enabled, so newer builds may start where older ones failed. The steps below still match what MSI documents and are the right place to start.

Fix it step by step

  1. Close other virtual machine programsQuit VirtualBox, VMware and any similar tool completely, including their tray icons, then try App Player again. MSI recommends this first.
  2. Confirm virtualization is enabledOpen Task Manager, select Performance, choose CPU and check Virtualization: Enabled. If it says Disabled, enable the Intel virtualization or AMD SVM setting in the BIOS.
  3. Turn off Memory integrityOpen Windows Security, go to Device security, select Core isolation details and switch Memory integrity off. Restart the PC so the change takes effect.
  4. Adjust Hyper-VIf it still fails, open Turn Windows features on or off and clear Hyper-V and related virtualization features, then restart. MSI's regional FAQ also gives the command bcdedit /set hypervisorlaunchtype off, run as administrator, to stop Hyper-V from loading.
  5. Update or reinstallDownload the current installer from MSI and reinstall. A newer build may handle Hyper-V without these changes.

The security trade off

Memory integrity protects Windows from malicious drivers. Turning it off to run an emulator lowers that protection. MSI's own Claw FAQ makes a related point: it suggests turning Memory integrity and Virtual Machine Platform off only while gaming, not permanently. If you rarely use App Player, turn Memory integrity back on afterwards. If you need it on all the time, check whether a newer build starts with Hyper-V enabled before you change anything.

If nothing works

Some workplace PCs lock virtualization or Memory integrity through policy, and you cannot change them. Older processors may lack hardware virtualization altogether. Check the MSI App Player system requirements first. If your PC cannot meet them, the MSI App Player alternatives page lists cloud and other options. Otherwise, reinstall the current build from the MSI App Player download page.

Frequently asked questions

What does Cannot start MSI App Player mean?

It means the emulator could not get the hardware virtualization it needs. According to MSI, another user of that feature, such as Hyper-V, VirtualBox, VMware or Memory integrity, is usually the cause.

Do I have to turn off Memory integrity?

Not always. Try closing VirtualBox or VMware and updating the emulator first. If it still fails, MSI's documented fix is to switch off Memory integrity under Core isolation and restart.

Is it safe to turn off Core isolation?

It lowers Windows' protection against malicious drivers. MSI's Claw guidance suggests turning these features off only while gaming, so switch Memory integrity back on when you are done.

MSI App Player is stuck on starting. What should I do?

Treat it like the Cannot start error. Close virtual machine programs, confirm virtualization is enabled in Task Manager, adjust Hyper-V and restart. If it still hangs, reinstall the current build from MSI.

Can I keep Hyper-V and use MSI App Player?

BlueStacks says version 5.20 and later run with Hyper-V on or off, on Windows 10 1903 or later or Windows 11. Whether your MSI build includes that depends on the version MSI ships, which MSI does not publish.
