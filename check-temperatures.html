To check CPU temperature with HWiNFO, start the program, tick Sensors-only on the welcome screen and read the processor and graphics entries in the sensors window. Values refresh every 2000 ms by default. The free edition is enough for this; you can add alerts, show up to 5 values in the on screen display and enable Auto Start to keep it running.

Before you start

You need HWiNFO on a Windows PC; the download page explains the installer and the portable package. Everything on this page works in the free edition. To check CPU temperature with HWiNFO you do not need the full hardware tree, which is why the program offers a mode that opens the sensors alone.

The vendor does not publish safe temperature limits for your hardware. Compare what you read with the maximum operating temperature in the specification from the maker of your processor or graphics card.

Steps

  1. Start HWiNFO and tick Sensors-onlyThe welcome screen has two options, Sensors-only and Summary-only. Tick Sensors-only to open just the sensors window. With both unticked you get every feature, including the hardware tree.
  2. Find the processor and graphics entriesThe sensors window groups readings by device: processors, graphics cards, mainboard, drives and peripherals. Temperatures sit alongside voltages, fan speeds, loads and clocks for each device.
  3. Let it run under loadStart the game or task you care about and leave the sensors window open. Values refresh on the polling period, 2000 ms by default, and version 8.54 allows a period as short as 20 ms.
  4. Set an alertHWiNFO can raise an alert when any monitored value reaches a threshold you set in the sensor settings. Use it for the processor and graphics temperatures you want to watch.
  5. Show values in a gameHWiNFO64 has its own on screen display. Pick the values to show in the sensor settings; the free edition shows up to 5 items, and since 8.54 several values can share a line.
  6. Keep it runningEnable Auto Start in the settings so HWiNFO starts with Windows; this creates a task in the Task Scheduler. Show Sensors on Startup opens the sensors window directly, and Minimize Sensors instead of closing keeps it out of the way.

Reading the sensors window

A modern PC exposes a long list of sensors, and HWiNFO shows all it can read. For a quick health check you need only a handful: the processor temperature, the graphics card temperature, drive temperatures and the fan speeds. Monitoring can be switched off for sensors you do not need, which shortens the list.

In Sensors-only mode the program places an icon in the system tray. Right click it to reach the Settings menu. If you want a record over time instead of a live view, continue with logging sensors to a CSV file.

Common problems

  • Only the summary appears and no sensors: Summary-only is ticked. Untick it on the welcome screen.
  • The welcome screen no longer appears: enable Show Welcome Screen and Progress in the settings, click OK and start HWiNFO again.
  • Stuck in Sensors-only with Auto Start on: the author's fix is to open HWiNFO64.INI and set SensorsOnly to 0.
  • Settings in a mess: the Reset Preferences button in the settings window restores the defaults.
  • A gadget stops receiving values after some hours: that is the 12 hour shared memory limit, explained under free vs Pro.

Frequently asked questions

How do I see CPU temperature in HWiNFO?

Start HWiNFO, tick Sensors-only on the welcome screen and look for the processor entries in the sensors window. Temperatures are listed with the other readings for each device.

Why does HWiNFO only show the summary?

Summary-only is enabled. Untick it on the welcome screen, or use Reset Preferences in the settings window if the welcome screen is hidden.

How often does HWiNFO update readings?

The default polling period is 2000 ms. It can be changed in the settings, and version 8.54 reduced the minimum to 20 ms.

Can HWiNFO start with Windows?

Yes. The Auto Start option creates a task in the Windows Task Scheduler. Combine it with Show Sensors on Startup to open the sensors window automatically.

What temperature is too high?

HWiNFO's vendor does not publish limits. Check the maximum operating temperature in the specification from the maker of your processor or graphics card and set an alert below it.
