What you get

The MSI App Player download installs MSI's edition of the BlueStacks Android emulator on Windows. Once it is installed, you sign in with a Google account to use the Play Store, as on any Android device, and install games and apps from there. MSI's page also offers to play on cloud, which streams a game in place of a local install.

Features you can use straight away include Console Mode for controllers, the Multi-Instance Manager for running several games at once, and keyboard and mouse control. How to use MSI App Player walks through each of them.

Because MSI does not list a spec sheet, the MSI App Player system requirements page uses BlueStacks' published minimums for the engine: 4 GB of RAM, 5 GB of free disk space and administrator rights on Windows.

Check these before you install

  • Virtualization is enabled. Open Task Manager, go to Performance, select CPU and look for Virtualization: Enabled.
  • You have administrator rights on the PC.
  • VirtualBox, VMware and other virtual machine programs are closed, because MSI notes they can conflict.
  • At least 5 GB of disk space is free, the BlueStacks engine minimum.

Install MSI App Player in five steps

  1. Open MSI's App Player pageUse the download button on this page. It takes you to MSI's official App Player page on msi.com.
  2. Download the installerChoose Download, not the cloud option, if you want the emulator on your PC. Save the file and run it.
  3. Approve and installAllow the installer to make changes when Windows asks, then let it install. It may need a restart if it changes virtualization components.
  4. Sign in to Google PlayOn first launch, sign in with a Google account so you can install games from the Play Store.
  5. Install a game and set controlsInstall a game, then play with keyboard and mouse, or connect a controller and turn on Console Mode.

If it will not open after installing

The most common problem MSI documents is the Cannot start MSI App Player message. It comes from a conflict with Hyper-V, other virtual machine software or Memory integrity in Windows Security. The page on how to fix the Cannot start MSI App Player error follows MSI's own steps.

Frequently asked questions

Is the MSI App Player download free?

Yes. MSI offers it as a free download and shows no price, trial limit or licence key. You only need a Google account to install games from the Play Store.

What is the latest version of MSI App Player?

MSI does not publish a version number on its App Player page. The installer you download from msi.com is the version MSI currently offers, so downloading from MSI keeps you on the official build.

How big is the MSI App Player installer?

MSI does not state the installer size. Plan for at least 5 GB of free disk space, which is BlueStacks' published minimum for its engine, and more if you install large games.

Does MSI App Player work on Windows 11?

MSI's page does not list supported Windows versions. BlueStacks documents Windows 10 version 1903 or later and Windows 11 for its engine when Hyper-V is enabled, and recent BlueStacks 5 builds run with Hyper-V on or off.

Can I download MSI App Player on a Mac?

MSI lists no Mac version. The program targets Windows PCs and the MSI Claw handheld.

Is there a refund policy?

No, and none is needed. MSI App Player is free, so there is nothing to buy or cancel.
