How to use MSI App Player: controllers, several games at once and the right GPU

How to use MSI App Player after installing it: sign in, install a game, turn on Console Mode for a controller, run several instances with the Multi-Instance Manager and make sure it uses your discrete GPU.

To use MSI App Player, sign in with a Google account, install a game from the Play Store and play with keyboard and mouse. For a gamepad, connect it and press Back + RB to turn on Console Mode. Use the Multi-Instance Manager to run several games at once, and on dual GPU laptops assign the emulator to the discrete card in Windows graphics settings.

First launch and your first game

This guide on how to use MSI App Player assumes it is already installed. If not, start with the MSI App Player download page. On first launch the emulator opens an Android home screen. Sign in with a Google account to unlock the Play Store, as you would on a new phone, then search for a game and install it. Games appear on the emulator's home screen and open in their own tab or window.

Keyboard and mouse work straight away. Many popular games ship with ready made key layouts in BlueStacks based emulators, but MSI does not document the controls editor on its own page, so check inside the game window for the controls option before remapping keys yourself.

Play with a controller in Console Mode

Console Mode is MSI's way of making touch games playable with a gamepad. MSI's forum announcement for the release that added it names MSI's own controllers plus Xbox, PS4 and Logitech pads, and says older versions may not support it.

  1. Connect the controllerPlug in or pair the controller with Windows before you open the emulator.
  2. Open MSI App PlayerLaunch the latest version. Console Mode needs a current build.
  3. Press Back + RBOn the controller, press Back and RB together to switch Console Mode on.
  4. Open a gameStart a game and play with the controller. Switch back to keyboard and mouse the same way if you need to.

Run several games with the Multi-Instance Manager

The Multi-Instance Manager creates separate Android instances, each with its own apps and accounts. MSI says you can run several games at once and set performance for each instance. A common use is keeping one game running in the background while you play another, or running two accounts of the same game.

Each instance takes its own share of RAM and CPU. BlueStacks lists 4 GB of RAM as the minimum for a single instance, so a PC with 8 GB will struggle with more than one or two heavy games. The MSI App Player system requirements page explains the engine minimums.

Make it use the right graphics card

MSI documents a case on AMD laptops where the emulator runs on integrated graphics instead of the discrete GPU. That caps frame rates well below what the hardware can do.

  1. Open Windows graphics settingsGo to Settings, then System, then Display, then Graphics.
  2. Add MSI App PlayerAdd the App Player program to the list if it is not there already.
  3. Choose the GPUOpen its options and select the high performance discrete GPU, then save.
  4. Confirm inside the emulatorOpen App Player's Settings and check the GPU in use field shows the discrete card.

Notes for the MSI Claw

On the Claw, Console Mode is the natural way to play, because the built in controls act as a gamepad. MSI's Claw performance FAQ suggests turning off Memory integrity and Virtual Machine Platform while gaming for better frame rates. The emulator relies on virtualization, though, so if App Player stops launching after you change those settings, see how to fix the Cannot start MSI App Player error. For an overall verdict on the Claw use case, read the MSI App Player review.

Frequently asked questions

How do I turn on Console Mode in MSI App Player?

Connect the controller to Windows first, then open the latest MSI App Player and press Back + RB on the controller. MSI's forum announcement says older versions may not support Console Mode, so update if nothing happens.

Which controllers work with MSI App Player?

MSI's announcement names MSI controllers plus Xbox, PS4 and Logitech controllers. Other gamepads that Windows recognises may work, but MSI does not list them.

Can I run two games at once in MSI App Player?

Yes. Open the Multi-Instance Manager, create a second instance and launch a game in each. Every instance uses its own RAM and CPU, so performance drops as you add more.

Why is MSI App Player using my integrated graphics?

Windows may assign it to the power saving GPU on dual GPU laptops. Set it to the high performance GPU in Windows graphics settings, then confirm in the GPU in use field in App Player's Settings.

Do I need a Google account?

Yes, to install games from the Play Store, as on any Android device. Use an account you are comfortable signing in to on a PC.
